# Changelog

## 1.0.2

- **The header ring now fills with what is done.** The done arc is drawn in the header's own colour and what is left is a faint track, starting at 12 o'clock. On a coloured header the done arc used to be the header's own colour, so it disappeared and the remaining part stood out instead. The count beside it is now readable on a coloured header too.
- **Rewards are only explained when there is one to give.** The "paid once" line under Finishing the journey now shows only when a points or badge reward is set and its extension is on, and it names what is set: points, a badge or both.
- **No "pts" without FoF Gamification.** The step list hides point and badge chips when the extension that pays them is off. The "needs a newer FoF Gamification" note only appears when Gamification is installed. New steps start at 0 points when points cannot be paid.

## 1.0.1

- **FoF Forum Widgets: "Your journey" is now placed in FoF's layout editor.** It is listed there as an available widget; drag it into a section and save. It used to register with a section name FoF does not have, so it could never be drawn, and the stock sidebar card stood down whenever FoF was installed, so members on a forum with FoF saw no journey card at all. Now the stock sidebar card shows unless the widget is placed, and the placed widget shows only for a member with an open journey.

## 1.0.0

First release: onboarding steps that tick themselves, 21 step types, rewards in FoF Badges badges and FoF Gamification points, the launcher, the journey page, reminders, the step editor and the funnel.
